# pyportscan

一个用 Python 实现的多线程 TCP 端口扫描器，用于学习网络安全和网络编程。

## 功能

- [x] 单端口 TCP Connect 扫描
- [x] 多端口范围扫描
- [x] 多线程并发加速
- [ ] 命令行参数（argparse）
- [ ] Banner Grabbing 服务识别
- [ ] 单元测试

## 环境

- Python 3.8+
